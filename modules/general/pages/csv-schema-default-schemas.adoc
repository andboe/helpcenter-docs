This article lists the settings of the default CSV schemas available in Peopleware.
For more information on CSV schemas see article xref:general:csv-schemas.adoc[CSV schemas].

[NOTE]
====
Your organization can change or delete the default CSV schema as provided by Peopleware.
====
[#forecast]
== Forecast
This default schema imports forecast data to the **Imported** time series of a workload.

The CSV schema settings are as follows:

[%header, cols="1a,1a,".rstrip(',')]
|===
|Setting
|Option
|Schema type
|`Forecast`
|Name
|`DEFAULT`
|Separator
|`Auto-detect`
|File has no header row
|Disabled
|Skip first x rows
|Empty
|Skip rows containing
|Empty
|===

The mapping of the default schema is as follows:

[%header, cols="1a,1a,".rstrip(',')]
|===
|Target field
|CSV column name or value
|Timestamp
|`Timestamp`
|Timestamp format
|`YYYY-MM-DD hh:mm`
|Offered
|`Offered`
|AHT
|`AHT`
|===
