[#time-zones-in-peopleware]
== Time zones in Peopleware
Peopleware supports scheduling across multiple time zones.

Each xref:administration:create-and-manage-planning-units.adoc[planning unit], xref:forecast:queues.adoc[queue], and xref:forecast:create-workloads.adoc[workload] has a time zone which you set when creating the item. You cannot change the time zone afterwards. If you need to change it, you have to recreate the item.

[NOTE]
====
Peopleware ensures that time zone settings are always applied correctly. For technical reasons, Peopleware sometimes changes the name of the time zone selected when you create an item, e.g. a planning unit. This does not affect the functionality.
====
The combination of the time zones of the elements and the time zone set for your user account determines how Peopleware displays data in the various features and functionalities.

[#set-your-user-time-zone]
== Set your user time zone
Your user time zone controls how data is displayed in features like the Shift Center, Schedules, and Dashboards. Change your user time zone to display data from the perspective of any time zone you want:

1. Click your *username* in the upper right.
2. Select a *Time Zone*.
3. Click btn:[Save Profile].

If you re-enter a feature, the data will shift according to your new user time zone.

Example: Your contact center operates in New York, but you work in Berlin. Set your user time zone to Berlin time and the planning unit time zone to New York time to see schedules in your local time. Change your user time zone to New York time to see schedules in the local time of the remote location, in this case New York time.

[#which-time-zone-is-used-by-which-feature]
== Which time zone is used by which feature?
Some features use the user time zone to display data, others the time zone defined for the planning unit or the workload. Some features also show the time offset between the user time zone and the planning unit or workload time zone. Learn which time zone is used in which features and where it is displayed.

[#shift-center]
=== Shift Center
The two main parts of the Shift Center - the schedule window and the parameter window - display data in the user time zone. If there is a time offset between the user time zone and the planning unit time zone, it is displayed in square brackets next to the name of the planning unit.

image::working-with-timezones/image-3.png[Time in Schedule View - Shift Center - Local user time, width=90%]

If you edit a day, the data is shown in the planning unit time zone during the editing.

image::working-with-timezones/image-4.png[Time in edit menu - planning unit time zone, width=80%]

[#schedules]
=== Schedules
The Schedules feature under {bc-plan-schedules} displays data in the user time zone. If there is a time offset between the time zone of the user and the planning unit, it is displayed next to the name of the planning unit.

image::working-with-timezones/image-11.png[Schedules Time Difference, width=80%]

If you edit a day, the data is shown in the planning unit time zone during the editing.

[#dashboards]
=== Dashboards
The Dashboards feature under {bc-analyze-dashboards} displays the data in the user time zone. You can see the current user time zone in the bottom right corner.

If you enter the editing mode by clicking on *!xref:ROOT:assets/img/common/dashboards/context-menu.png[Context menu]* and then on *Edit*, the navigator opens to the left. To the right of the elements in the navigator, you can see the time zone of the respective planning unit or workload.

image::working-with-timezones/image-12.png[Dashboards navigator - tree view, width=80%]

[#me]
=== Me
Me displays shifts and activity times in the user time zone.

[#reports]
=== Reports
The reports which you create with the Reports feature under menu:WFM[Monitoring>Reports] display data in the time zone of the planning unit. The report header also displays the time offset between the time zone of the planning unit and the user time zone.

image::working-with-timezones/image-7.png[Planing unit time zone and offset for the user, width=60%]

[#forecast]
=== Forecast
The workload feature under menu:Forecast[] shows data in the time zone set for the workload. The time zone of the workload is displayed to the right of the workload name in the drop-down menu.

*Forecast* displays data using the time zone that is set for the workload. You can see the time zone of the workload in these places:

- the workloads list
- next to the workload name in the drop-down menu

The values in the volume and AHT graphs in workloads do not default to the time zone set in xref:getting-started:navigate-peopleware.adoc#your-user-profile[your user profile]. To see values according to your profile's time zone, go to {bc-analyze-dashboards} and add workload data to a dashboard.

[#requirements-calculation-window]
=== Requirements calculation window
Staff requirements are calculated in the time zone of the planning unit. The calculation considers the time offset between queue and planning unit timezone.

For more information on how Peopleware calculates staff requirements, see xref:forecast:concept-staff-requirements.adoc[Staff requirement basics].
