1. Go to {bc-account-integrations}.
2. {btn-create}

4. From the *External system* drop-down menu, select *Vonage*.
5. {btn-save}

[#set-up-your-vonage-integration]
== Set up your Vonage integration
1. In the *Credentials* section, enter the following information:
   - *Client ID* and *Client secret*: Enter a valid client ID and client secret for your Vonage ACD. If you created user-level API credentials in Vonage for a non-admin user, select at least "View Insights Stats" in Scopes.
2. In the *Configuration* section, configure the following fields:
   - *Account region*: Select the region of your Vonage account.
   - *Group queues by*: Select how you want to group your queues. The selection cannot be changed once it has been saved. The Vonage queues option combines data from queue type, queue name, and interaction plan.
3. {btn-save}
