[#add-a-freshdesk-contact-center-integration]
== Add a Freshdesk Contact Center integration
To add a new Freshdesk Contact Center integration, you need a Pro or Enterprise Freshdesk Contact Center account.

1. Go to {bc-account-integrations}.
2. {btn-create}
3. include::ROOT:partial$ui-interactions/enter-integration-name.adoc[]
4. From the **External system** drop-down menu, select **Freshworks**.
5. From the **Model name** drop-down menu, select **Freshcaller**.
6. {btn-save}

[#set-up-your-freshdesk-contact-center-integration]
== Set up your Freshdesk Contact Center integration
1. In the **Credentials** section, set up the access to your Freshdesk Contact Center account:
   - **Domain**: Enter your full Freshdesk Contact Center domain name including the subdomain, e.g. example.freshchat.com.
   - **API key**: Enter a valid API key of a Freshdesk Contact Center user with the Account Administrator role. You can find the key in the API Tokens page under Admin > Configure.
2. In the **Configuration** section, select the xref:#queue-names-by-grouping-strategy[grouping strategy for imported queues].
3. {btn-save}

After you have saved the configuration, proceed in the **Install the Peopleware app** section on the page.

[#install-the-peopleware-app]
== Install the Peopleware app
Peopleware can only receive data from Freshdesk Contact Center when you set up the Peopleware Freshcaller app in your Freshworks account:

1. In the **Install the Peopleware app** section, generate and copy the **Peopleware API key**.
2. Set up the app in the [Freshworks marketplace](https://www.freshworks.com/apps/injixo_1/).
3. In the Peopleware app installation page, paste the copied API key.
4. To import data in real time, check the **Export real-time agent status data** checkbox in the app installation page of the Freshworks marketplace.

After you have installed the app, you can see new queues in your workloads and Forecast and xref:acd-integration:import-agent-status-data.adoc#map-external-identifiers-to-people-in-peopleware[map external identifiers] to your people in Peopleware.

[#queue-names-by-grouping-strategy]
== Queue names by grouping strategy
When importing data, the grouping strategy affects the names of the queues that are created in Peopleware:

[%header, cols="1a,1a,1a,".rstrip(',')]
|===
|Grouping strategy
|Queue name
|Example
|Phone number
|Phone number
|+49123456789
|Routing (team/agent)
|Team name
|Tech Support Team
|Routing (team/agent)
|Agent name (if no team name is assigned)
|Agent 1
|===

For calls that have no group in Freshdesk Contact Center, the queue name is Undefined_Queue.
