This article lists all queue settings available in menu:Analyze[Configuration].

== Queues

=== General

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Name**
|Queue name
|**Abbreviation**
|Abbreviation for the queue name
|**Interval**
|Time increments (e.g., 15 min, 30 min, 1 hr) at which Peopleware imports queue data.
|**Description**
|Optional description of the queue
|**Parent queue**
|Primary queue under which the current queue is grouped.
|**Time zone**
|Specific geographical region time standard applied to the queue's data.
|===

Clicking a queue opens the queue details page.

=== Event types

The list of event types that apply to the queue.

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Name**
|Event type name
|**From**
|Start time of the event type
|**To**
|End time of the event type
|**+Add**
|Opens the **Add event types** page.
|===

==== Add event types

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Search field**
|Allows event type search by name.
|**From**
|Edits the event type start time.
|**To**
|Edits the event type end time.
|===

=== Value types

The list of value types that apply to the queue.

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Name**
|Event type name
|**Formula**
|Value type formula. Only applies to virtual value types.
|**+Add**
|Opens the **Add event types** page.
|===

== Value types

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Search field**
|Allows value type search by name.
|**ID**
|Value type ID
|===

=== Create

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|**Name**
|Value type name
|**Abbreviation**
|Abbreviation for the value type name
|**Aggregation type**

|**Description**

|===
