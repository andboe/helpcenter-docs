The _People_{:.breadcrumbs} page provides two types of search filters:

- Standard filter
- xref:people:advanced-filters.adoc[Advanced filters]

== Use the standard filter

The standard filter allows you to filter people by the following criteria:

- Role
- Planning unit
- Selection
- Contract
- Skill
- Profile status

To use the standard filter, proceed as follows:

1. Click the {icon-filter-plus}.
2. Hover over the filter criterion you want to use. The list of objects appears.
3. Select the options you want to use for filtering.

Repeat this operation if you want to filter by more than one object.
To remove a filter, click _x_{:.doc-button}.

== Use the advanced filter

Advanced filters are predefined sets of custom filter criteria. Use advanced filters to apply filter criteria quickly without the need to specify them manually for each search. Learn more about advanced filters and how to xref:people:advanced-filters.adoc[configure them].

To use an advanced filter, go to _People_{:.breadcrumbs} and proceed as follows:

1. Click the {icon-filter-plus}.
1. Select _{icon-two-lines-with-circles} Advanced_{:.doc-button}.
1. Select an advanced filter.

The list updates automatically.
To clear the filter, click _{icon-circle-xmark}_{:.doc-button}.
To edit your advanced filters, click **Manage advanced filter** in the advanced filter dropdown.
