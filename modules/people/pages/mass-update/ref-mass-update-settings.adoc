== Skills

=== Add skill

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|*From*
|Specifies the start date of the period affected by the mass update.
|*To*
|Specifies the end date of the period affected by the mass update.
|*Skill*
|Specifies the skill that the mass update assigns to the selected people.
|*Skill level*
|Specifies the skill level of the skill.
|*Overwrite current skill level*
|Controls if the mass update replaces the skill level of any existing assignment of the newly added skill with the skill level specified for the Add action. This option extends the option *Add only to empty time periods* by ensuring that all assignments of the added skill in the mass update period have the same skill level. This option has no effect on skills other than the added skill.
|*Add only to empty time periods*
|Controls if the mass update adds the object only to periods within the mass update period that do not already have an assignment of the added object type. For skills, the *Overwrite current skill level* extends this option.
|*Add to empty time periods and overwrite existing assignments*
|Controls if the mass update removes within the mass update period any existing object assignment of the selected object type and then assigns the new object for the whole mass update period.
|===

---

== Attributes

=== Add attribute

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|*From*
|Specifies the start date of the period affected by the mass update.
|*To*
|Specifies the end date of the period affected by the mass update.
|*Attribute*
|Specifies the attribute that the mass update assigns to the selected people.
|*Value*
|Specifies the value of the assigned attribute.
|*Priority*
|Specifies the priority of the assigned attribute value.
|*Overwrite current values*
|If the specified attribute and priority combination is already assigned in the mass update period, the setting controls if the Add action overwrites the old attribute value. If the setting is inactive and the same attribute and priority combination is already assigned, the mass update automatically lowers the priority of the existing attribute and priority combinations with the same or a lower priority.
|===

---

=== Delete attribute

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|*From*
|Specifies the start date of the period affected by the mass update.
|*To*
|Specifies the end date of the period affected by the mass update.
|*Attribute*
|Specifies the attribute that the mass update unassigns from the selected people.
|*Delete all included values*
|Controls if the mass update removes every assignment of the selected attribute, regardless of the attribute value.
|*Delete specific values only*
|Controls if specific values need to be selected for the Delete action. The mass update only removes assignments of the attribute that have these values.
|*Values*
|Specifies a set of values of the selected attribute. The mass update only removes assignments of the attribute that have these values.
|===

|*Contract*
|Specifies a contract. Mass update adjusts the contract validity for every assignment of that contract within the mass update period.
|===

==== New assignment

[%header, cols="1a,1a,".rstrip(',')]
|===
|Field
|Description
|*Valid from*
|Controls if the mass update changes the start date of the contract assignment. If in the mass update period more than one assignment exists for the selected contract, the mass update only adjusts the Valid from date of the assignment with the earliest Valid from date.
|*Valid to*
|Controls if the mass update changes the end date of the contract assignment. If in the mass update period more than one assignment exists for the selected contract, the mass update only adjusts the Valid to date of the assignment with the latest Valid to date.
|*New date*
|Specifies the value for the *Valid from* or *Valid to* setting.
|===
