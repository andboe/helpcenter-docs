[#what-are-planning-periods-used-for]
== What are planning periods used for?
Planning periods are time periods of a few days, weeks or months up to one year. They are used for various planning purposes (see below), thus their name.

[#types]
=== Types
There are two types of planning periods: standard planning periods and activity-based planning periods.

image::what-are-planning-periods/image-2.png[Different planning period types, width=80%]

Use _standard planning_ periods if you want to:

- allow employees xref:scheduling:enable-employees-to-see-their-schedules.adoc[to see their schedules].
- allow employees xref:scheduling:enable-employees-to-swap-shifts.adoc[to exchange shifts] with each other.
- activate xref:scheduling:shift-bidding.adoc[shift bidding] for employees.
- edit or xref:administration:concept-target-work-times.adoc[calculate target work times] for employees.
- xref:scheduling:batch-replace-an-activity.adoc[batch replace one activity] in your schedule with another.
- xref:scheduling:copy-and-back-up-schedules.adoc[copy or back up schedules].
- xref:scheduling:delete-schedules.adoc[delete schedules].

Use _activity-based planning periods_ if you want to allow employees to xref:scheduling:enable-time-off-and-request-sick-leave.adoc[request time off or to add sick leave]. Activity-based planning periods use activities that have been configured as **Requestable in Me**. These are activities of the type _Absence_, _Vacation_, or _Illness_. You have to create a separate planning period for each activity, e.g. one for adding vacation requests and one for adding sick leave.

[#status]
=== Status
The status of a planning period determines how employees can interact with it. Typically, you will change the status of a planning period multiple times during the scheduling process, such as after you have finalized the schedule or once the shift bidding period is over.

[%header, cols="1a,1a,".rstrip(',')]
|===
|Status
|Explanation
|Locked
|Employees cannot see the published schedule, cannot participate in xref:scheduling:shift-bidding.adoc[shift bidding], cannot exchange shifts with each other, and cannot request time off. Use this status if you don't want to release the schedule to your employees yet.
|Enabled
|Employees can see the published schedule, can participate in shift bidding, can request time off, and can exchange shifts with each other. This status _cannot be set_ if the planning period has a deadline that has already expired.
|Information
|Employees can see the published schedule and can exchange shifts with each other. They _cannot_ participate in shift bidding and cannot request time off. This status is only relevant for planning periods of the type _Standard_.
|Closed
|Use this status to indicate that the schedule is final. Employees can still exchange shifts with each other.
|===

As you can see, planning periods are used in many different ways. Click one of the links in the list above to get detailed instructions for the different use cases.

[#filter-and-display-planning-periods]
== Filter and display planning periods
If you go to _WFM > Scheduling > SchedulePro > Planning Periods_{:.breadcrumbs}, you will initially see no planning periods. You first have to set a filter to choose the planning periods you want to display.

1. Choose a _Planning Unit_{:.label}.
2. Choose a **Type**.
3. Choose a _Selection_{:.label} (optional). The selection field is not available in Essential WFM.
4. Click _Apply_{:.doc-button} to display the corresponding planning periods. If there are no matches with the filter criteria, nothing will be shown.

image::what-are-planning-periods/image-1.png[Planning Periods, width=80%]

The _inherited_ column flags planning periods of parent planning units. You can calculate time accounts and target work times on parent planning units for all child planning units or for each one individually. When you create a planning period for a parent planning unit, its status is inherited by any child planning units.

[#create-a-new-planning-period]
== Create a new planning period
To create a new planning period, use the _![add button](/assets/img/common/item-add.gif)_{:.doc-button-icon} button from the action bar. A dialog to set the time period and status of the new planning period appears. Since this information depends on what you want to achieve with the planning period, you can find more information in the articles at the top on the different use cases.

[#edit-a-planning-period]
== Edit a planning period
The typical reason to edit a planning period is to update its status. To edit a planning period, select it. Then click the _![edit button](/assets/img/common/item-edit.gif)_{:.doc-button-icon} button from the action bar.

[#delete-a-planning-period]
== Delete a planning period
To delete a planning period, use the _![delete button](/assets/img/common/item-delete.gif)_{:.doc-button-icon} button from the action bar.
