== Allow time-off requests and sick leave
To allow _time-off requests_ or sick leave, you first have to activate the option in Me. Click menu:Me[] in the main navigation and turn on **Time Off Requests**.

1. Go to menu:WFM[Scheduling>SchedulePro>Planning Periods].
2. Choose the *Planning Unit* you want to allow time-off requests for.
3. As **Type**, choose one of your requestable activities. Learn how to configure an xref:administration:activities.adoc[activity as **Requestable in Me**]. Then add the activity to the xref:administration:create-and-manage-planning-units.adoc[planning unit].
4. Choose a *Selection* if you want to limit time-off requests to a certain group of agents. Otherwise, keep **[All]**.
5. Click btn:[Apply].
6. If a matching planning period exists, select it and click the *![edit button](/assets/img/common/item-edit.gif)* button in the action bar. If there is no suitable planning period in the list, create a new one by clicking the {icon-wfm-add} button in the action bar.

In both cases, the following dialog appears:

image::enable-time-off-and-request-sick-leave/image-3.png[Define Planning Period, width=60%]

1. Use **Valid From** and **Valid To** to define a time period, e.g. three months or the entire year. A planning period for vacation or other absences is usually longer than just a week.
2. Select the **Status** _Enabled_.
3. Optional: Set a **Deadline**. Until that date, employees can request time off.

Your employees will now see the option to request time off in Me for the time period defined by the planning period. As a planner, you can then xref:scheduling:vacation-absences-management.adoc[approve or reject] time-off requests.
